# ピクトポーズ 要件定義・実装計画

## 1. 目的

作業マニュアル、教育資料、安全資料を作る人が、既製ピクトグラムでは表現しにくい「少しだけ違う手足の位置」を、専門的なデザインソフトなしで作れるようにする。

主な利用者は個人サイトの閲覧者と社内資料の作成者。人物の姿勢データだけを扱い、会社の図面・写真・文章をアップロードしなくても使える構成を基本とする。

## 2. プロダクト原則

1. 20前後の姿勢から最も近いものを選ぶ。
2. 頭、肩、肘、手、腰、膝、足首をドラッグして仕上げる。
3. 1分以内にSVGまたはPNGを取得する。
4. MVPでは入力も編集もブラウザ内で完結させ、サーバーへ素材を送らない。
5. 指の形より、作業内容が伝わる全身のシルエットを優先する。

## 3. MVP（フェーズ1）

### 機能要件

- 姿勢プリセット：直立、正面、歩行、走行、しゃがみ、膝立ち、片膝、座位、下を見る、横から覗く、点検、持ち上げ、運搬、押す、引く、手を伸ばす、方向指示、停止合図など。横向きは直立、歩行、かがみ、片膝、手伸ばし、散水に対応
- 関節編集：頭、首、左右の肩・肘・手・腰・膝・足首
- 手の表現：丸のみ。指、握り、開いた手は対象外
- 安全装備：ヘルメットと墜落制止用器具を別々にON／OFF
- 手持ちアイテム：左右の手にスパナ、ドライバー、ハンマー、電動ドリル、スプレー、散水ノズルを配置し、角度と大きさを調整
- 操作：ドラッグ、矢印キーの1px移動、Shift＋矢印の10px移動
- 編集補助：元に戻す、やり直す、リセット、左右反転
- 見た目：色、手足の太さ、頭の大きさ、透明／白背景
- 出力：編集ハンドルを含まないSVG、1200×1320px PNG
- 端末：PCを主対象とし、タブレット・スマートフォンのタッチ操作にも対応
- データ：ログイン、データベース、アップロードなし

### 非機能要件

- 初回表示後の姿勢編集はネットワーク接続なしでも継続できること
- 通常の編集・保存処理で利用者の姿勢データをサーバー送信しないこと
- SVGはPowerPoint、Word、Google Slides、Illustrator等へ持ち込めること
- キーボード操作、フォーカス表示、読み上げ用ラベルを備えること
- 最新のChrome、Edge、Safari、Firefoxを対象とすること
- 生成物へサービスの透かしを入れないこと

### MVPの対象外

- 指、手袋、握り方の精緻な編集
- 3D人体、遠近法、関節の物理制約
- ユーザーアカウント、クラウド保存、共同編集
- 写真や社内マニュアルのアップロード
- AIによる自動生成
- 医療・人間工学評価に使える姿勢判定

## 4. データモデル

姿勢は400×440の座標系における14関節のJSONとして表す。

```ts
type Pose = {
  head: Point;
  neck: Point;
  shoulderL: Point;
  elbowL: Point;
  wristL: Point;
  shoulderR: Point;
  elbowR: Point;
  wristR: Point;
  hipL: Point;
  kneeL: Point;
  ankleL: Point;
  hipR: Point;
  kneeR: Point;
  ankleR: Point;
};
```

表示用SVGはこのデータから毎回生成する。プリセット、GUI編集、将来のAI生成が同じ `Pose` を入出力するため、生成方法が増えてもエディタ本体を作り直さない。

現在は `view: front | side` を持ち、道具は左右の手首座標へ追従する。フェーズ2で `threeQuarter`、任意アンカー、前面／背面レイヤーを追加する。

## 5. フェーズ計画

### フェーズ1 — 編集できるMVP

- 20前後の作業向け基本姿勢
- 関節ドラッグと数値的な微調整
- SVG／PNG出力
- Cloudflare公開
- 利用者5〜10人による「目的の姿勢まで1分以内」の確認

完了条件：代表的な作業マニュアル5例について、外部デザインソフトを使わず人物図を作成できる。

### フェーズ1.5 — 道具・横向き・安全装備（実装済み）

- スパナ、ドライバー、ハンマー、電動ドリル、スプレー、散水ノズル
- ヘルメット、墜落制止用器具の独立切替
- 横向きの代表姿勢6種類
- 道具の回転、拡大縮小
- 左手／右手へのスナップ
- 人物＋道具を1つのSVGとして保存

残課題：箱、台車、点検器具など手首以外へ置く大型アイテムと、人物の前面／背面レイヤー切替。

完了条件：頻出する10種類の道具を、手首に追従させて配置できる。

### フェーズ2 — 手・向き・表現の拡張

- 丸、握る、指す、開く等の手パーツ
- 正面、側面、斜めの体向き
- 顔の向き、視線、腰・胴体の回転
- 補助線、動作線、注意記号
- 姿勢JSONの保存／読み込み

完了条件：道具の握り方と作業対象への視線を、資料用途として違和感なく表現できる。

### フェーズ3 — APIによるたたき台生成

- 「しゃがんで右手で配管の下を覗く」等の自然文を `Pose` JSONへ変換
- 画像から骨格候補を抽出し、GUIで最終調整
- 出力JSONをスキーマ検証し、範囲外座標や欠損関節を補正
- AI出力は自動確定せず、必ず編集画面へ戻す
- 会社利用時は外部API送信のON/OFF、送信範囲、保存方針を明示

完了条件：頻出指示20件のうち80%以上で、近いプリセットを探すより早く編集開始点を得られる。

## 6. 技術構成

- UI：React 19 / Next.js 16 App Router
- 描画：ブラウザ標準SVG。CanvasライブラリはMVPでは導入しない
- 状態：React state。サーバー永続化なし
- 書き出し：SVG DOMシリアライズ、Canvas経由のPNG変換
- 配信：MVPはCloudflare Pagesの静的配信。API追加時はCloudflare Workersへ拡張
- CI/CD：GitHubをCloudflare Pagesへ接続し、main更新時に自動公開
- テスト：型チェック、ビルド、主要操作のブラウザテスト、SVG構文確認

## 7. セキュリティ・会社利用

- MVPは完全クライアント処理とし、姿勢座標や出力画像を保存しない
- 解析を導入する場合も、編集内容・ファイル名・出力SVGをイベントへ含めない
- AI生成を追加するまではAPIキーを持たない
- AI生成追加時は外部送信を明示し、社内利用向けに無効化できる構成とする
- 参考画像や他社ピクトグラムをトレースせず、プリセットは独自の関節座標から生成する
- コードはMIT License。利用者が生成した出力にサービス固有の利用制限を追加しない

## 8. 成功指標

- 初回利用者の80%以上が説明なしでSVGを保存できる
- 代表姿勢の作成時間中央値が60秒以内
- プリセット選択後の関節移動回数中央値が6回以下
- SVGをPowerPointへ貼り付けた際、拡大しても輪郭が劣化しない
- 社内ネットワークから外部へ素材を送らず利用できる

## 9. 実装順序

1. 関節データとSVGレンダラー
2. 作業向けプリセット
3. ドラッグ、キーボード、Undo/Redo
4. スタイル設定とSVG/PNG出力
5. レスポンシブ・アクセシビリティ調整
6. ビルド、操作試験、Cloudflare公開
7. GitHub新規リポジトリと自動デプロイ接続
8. 利用テスト後に道具機能へ進む
