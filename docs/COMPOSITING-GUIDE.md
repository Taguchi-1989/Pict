# 自作ワークとの合成規約（アイソメ・パターン）

人物はピクトポーズでフラットに作り、ワーク（被加工物・作業対象）は自作のアイソメ風SVGで描いて、PowerPoint等で重ねるためのルール。

## 座標系

- キャンバスは **400×440**（書き出しSVGのviewBoxと同一）
- **床線は y=398**。人物の足元がここに接地する。ワークもこの床線上に置けば、重ねるだけで接地位置が揃う
- 推奨2色：主色 `#111111`、補助色 `#7b8480`（アプリの初期値と同じ）

## 人物側の書き出し

1. アプリの「書き出し範囲」で **人物のみ** を選ぶ（作業台などのシーンと床グリッドを除外。溶接面など人物に付く装備は残る）
2. 必要なら「奥行き表現」で **接地影** をON（アイソメのワークと並べると接地感が揃う）
3. 背景は **透明** のままにする

書き出したSVGのルート要素には合成用のアンカー座標が入っている：

| 属性 | 内容 |
|---|---|
| `data-floor-y` | 床線のY座標（常に398） |
| `data-anchor-wrist-left` / `data-anchor-wrist-right` | 左右手首の `x,y`。工具や把持位置をワーク側に合わせるときの基準 |
| `data-anchor-hip-center` | 腰中心の `x,y` |
| `data-anchor-head` | 頭中心の `x,y` |

## ワーク側の作り方

1. アプリ内の「ワーク用アイソメテンプレSVGをダウンロード」からテンプレ（`work-template-iso.svg`）を取得
2. `id="your-work"` グループ内に、**30°のアイソメ**でワークを描く（`sample-work` に箱の見本あり：左面=濃 `#5f6763`、右面=補助色 `#7b8480`、上面=淡 `#c1c7c3`、輪郭 `#111111` 幅3）
3. 床線 y=398 に接地させる
4. 完成したら `guide` と `sample-work` のグループを削除

## 合成

PowerPoint等で人物SVGとワークSVGを同じサイズで重ねる（両方とも400×440の同一キャンバスなので、左上を揃えるだけで位置が合う）。前後関係はスライド上の重なり順で調整する。

人物の腕をワークの**後ろ**に回す表現はこの方式では不可（人物SVGを分割できないため）。その表現が必要な作業が出てきたら、アプリ側の前面/背面レイヤー機能（SOP-INTEGRATION-REVIEW.md の P2-3）を検討する。
